Sign in with a GitHub token

Publishing commits a change to the website's repository, so this page needs a GitHub token with write access to it. The token is sent only to api.github.com and is kept in this browser — nowhere else.

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → friendsoflakemattoon.github.io.
  3. Permissions: Contents: Read and write and Pull requests: Read and write. Nothing else.
  4. Set an expiration (90 days is sensible), generate, and paste it below.
